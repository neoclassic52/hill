# OKA — ただ、丘を眺める。

あの懐かしい「緑の丘と青い空」を、Three.js でリアルタイムに描いた小さな作品です。

**▶ https://neoclassic52.github.io/hill/**

## できること

- **時刻**：夜明け・朝・昼・夕焼け・夜。「時間を進める」で1日が流れる
- **そよ風**：突風の波が草原を渡る
- **雲のスピード**：雲と、丘に落ちる雲の影が流れる
- **虹**：雨あがりの二重の虹
- **季節**：春の新緑・夏・秋の金色・冬の雪原
- **天気**：晴れ・くもり・雨・雪
- **実写度**：0 は壁紙のような鮮やかさ、MAX は写真のような自然な色と長い草
- **懐かしさ**：ブラウン管モニター風の走査線とにじみ
- **生き物・流れ星・環境音**（環境音はすべてブラウザ内で合成）

ドラッグで見渡す・ホイール / ピンチで近づく・マウスでなでると草がなびきます。

## 使い方

`index.html` をブラウザで開くだけで動きます（three.js を CDN から読み込むためネット接続が必要です）。

同じフォルダに `startup.mp3` を置くと、起動時にその音が鳴ります。置かない場合はオリジナルの起動音を合成して鳴らします。
